# ADR-0004: The `-test` org carries the fixtures and the conformance run

## Status

Accepted — 2026-09-05.

## Context

Every org in the fleet has a sibling `-test` org for external-facing testing and its own
GitHub Actions minutes. A loading layer needs realistic build trees to test against — a
Flutter web release, a Leptos islands release, a Dioxus route-chunk release — and a
cross-browser matrix that is far more expensive to run than a unit suite.

## Decision

`ores-wasm-loaders-test` holds `owls-e2e` (structurally faithful build trees, their
manifests, and the shared test kit) and `owls-e2e` (the adapter conformance suite and
the browser matrix). The production org depends on the fixtures only in tests.

Fixture trees are generated by a committed script rather than committed as binaries: they are
deterministic, so digests are stable, and the repository stays small.

## Consequences

* The expensive matrix spends the test org's Actions minutes, not the product orgs'.
* An org that writes its own adapter has a conformance target it can run without adopting our
  frameworks.
* Fixtures imitate the shape of real build output and never copy a vendor's assets.
